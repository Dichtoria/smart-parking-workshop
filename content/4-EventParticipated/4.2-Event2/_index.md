# Summary Report: “Seminar AI From Scratch”

### Event Objectives

The "AI From Scratch" seminar was organized for students and software developers to gain a comprehensive perspective on applying Artificial Intelligence (AI), Machine Learning (ML), and Generative AI on AWS. The event guided attendees from pre-built AI Managed Services, multi-language AI Agent architectures, MLOps workflows with Amazon SageMaker, to hands-on experiences building intelligent Chatbots with Amazon Bedrock and participating in an interactive voice-controlled game.

### Speakers & Advisors

- **Nguyen Tuan Thinh** – DevOps/Cloud Engineer, AWS Vietnam
- **Nguyen Cong Minh** – DevOps Engineer, AWS Vietnam
- **Mr. Mai Hoang Dinh** – IA Lecturer, FPT University HCMC (Academic Advisor)
- **Technical Specialist Team** – AWS Vietnam Representatives

### Key Highlights

#### 1. AWS AI Managed Services Ecosystem & AI Agent Architecture
- **Specialized AI Services Overview**: Explored pre-built AI tools accessible via APIs:
  - *Amazon Transcribe*: Speech-to-Text conversion.
  - *Amazon Translate*: Automated multi-language translation.
  - *Amazon Comprehend*: Sentiment analysis, topic and keyword extraction.
  - *Amazon Lex*: Natural Language Understanding (NLU) and conversation intent identification for Chatbots.
  - *Amazon Polly*: Text-to-Speech natural voice synthesis.
  - *Amazon Textract*: Intelligent document processing and Optical Character Recognition (OCR).
  - *Amazon Rekognition*: Image recognition, facial analysis, and product defect detection.
- **6-Step Architecture for a Multilingual Customer Support AI Agent**:
  1. *Transcribe*: Capture incoming calls and convert speech to text.
  2. *Translate*: Translate text into target standardized languages.
  3. *Comprehend*: Analyze call sentiment and key topics.
  4. *Lex*: Identify user intent and extract slots.
  5. *Backend Integration*: Execute business logic APIs and query databases.
  6. *Polly*: Respond to customers using natural synthetic voice.

#### 2. Building & Training ML Models with Amazon SageMaker
- End-to-end MLOps workflow demonstration: Data preparation, custom model algorithm selection, automated hyperparameter tuning, and deploying Real-time Inference Endpoints using Amazon SageMaker.

#### 3. Exploring Generative AI & Chatbot Deployment with Amazon Bedrock
- Overview of Amazon Bedrock for securely accessing Foundation Models (FMs) such as Anthropic Claude and Meta Llama. Practical guidance on Prompt Engineering and Retrieval-Augmented Generation (RAG) for enterprise chatbot applications.

#### 4. Interactive Voice-Controlled Game Demo Experience
- Live experience playing an innovative demo game developed by AWS engineers. The game combined Amazon Transcribe and Amazon Lex, allowing players to issue real-time voice commands via microphone to control character movements and actions.

### Key Takeaways

#### Design Mindset
- **AI-First Application Mindset**: Mastered combining pre-built AI Managed Services via APIs to compress product development timelines from months to days.
- **Multi-channel Agent Design**: Understood combining voice processing, translation, sentiment analysis, and backend API integration.

#### Technical Architecture
- **Standardized AI Agent Architecture**: Understood 6-step voice/text processing pipelines alongside complementary OCR (Textract) and Computer Vision (Rekognition) inputs.
- **Generative AI & MLOps Practices**: Gained clear insights into Amazon Bedrock operations and end-to-end Machine Learning model deployments on Amazon SageMaker.

#### Modernization Strategy
- Leveraging cloud computing to simplify embedding sophisticated AI/ML capabilities into production applications without upfront GPU hardware investments.

### Applying to Work

- **AI Service Integration**: Applying Amazon Transcribe, Polly, and Lex to build automated voice/chatbot features into application projects.
- **Document & Vision Automation**: Utilizing Amazon Textract and Rekognition to automate document parsing and image verification workflows.
- **Generative AI Research**: Experimenting with Amazon Bedrock and database integration to build intelligent knowledge search assistants.

### Event Experience

The "AI From Scratch" Seminar at the FPTU Library provided an engaging and highly educational environment. The highlight was participating in the voice-controlled game and interacting with speakers Nguyen Tuan Thinh, Nguyen Cong Minh, and Lecturer Mai Hoang Dinh, making complex AI/ML concepts intuitive and accessible.
