# Summary Report: “Cloud Architect Final & Technical Sharing”

### Event Objectives

The Cloud Architect Final & Technical Sharing event delivered a high-caliber technical atmosphere, combining a competitive cloud architecture design final with deep technical sharing sessions by AWS experts: spanning multi-layer web application security, SLA-driven monitoring techniques, and strategic roadmaps for acquiring AWS Cloud Practitioner certifications.

### Speakers

- **KLKAT Team & Ngu Dai Hiep Team** – Finalist Speakers for the Cloud Architect Competition
- **Thinh Nguyen** – Speaker for *Securing Your Web Apps With AWS Security Agent*
- **Nguyen Huynh Son** – Speaker for *SLA and Monitoring: From SLA to Monitoring What Really Matters*
- **Ngo Le Tan Huy** – Speaker for *Inside The Exam: AWS Cloud Practitioner*

### Key Highlights

#### Event Opening: Cloud Architect Competition Final (KLKAT vs. Ngu Dai Hiep)
The event commenced with an intense final competition between two outstanding teams: KLKAT and Ngu Dai Hiep. Through their presentations, I observed how teams dissect complex business requirements, architect optimal cloud solution diagrams, defend technical choices, and handle challenging queries from the judging panel.

#### 1. Thinh Nguyen - Securing Your Web Apps With AWS Security Agent
- Provided a deep dive into multi-layered security frameworks for web applications hosted on AWS. The speaker analyzed defense-in-depth principles, attack surface reduction techniques, and the strategic importance of automated monitoring and early anomaly detection to mitigate cyber threats proactively.

#### 2. Nguyen Huynh Son - SLA and Monitoring: From SLA to Monitoring What Really Matters
- Delivered a fresh perspective on Service Level Agreements (SLAs) and effective monitoring systems. The talk stressed that system monitoring extends beyond viewing infrastructure dashboards — it must align directly with end-user experiences, system availability, and core operational goals.

#### 3. Ngo Le Tan Huy - Inside The Exam: AWS Cloud Practitioner
- Offered a comprehensive roadmap for achieving the AWS Cloud Practitioner certification. The speaker shared methods for organizing foundational knowledge, allocating study time effectively, real-exam strategies, and accurate study resources. This session inspired me to pursue AWS technical certifications.

### Key Takeaways

#### Design Mindset
- **Practical Architecture Mindset**: Learned requirement analysis, optimal AWS service selection, and architecture defense techniques from finalist teams.
- **User-Centric Monitoring Mindset**: Shifted monitoring perspectives from raw hardware metrics to SLA quality indicators directly impacting user experiences.

#### Technical Architecture
- **Multi-Layer Web Security (Defense-in-Depth)**: Understood core principles of deploying AWS Security Agents for proactive vulnerability detection and web application safety.

#### Modernization Strategy & Personal Growth
- **AWS Certification Roadmap**: Mastered structured preparation methods and time allocation tactics for the AWS Cloud Practitioner exam.
- **Technical Synthesis Skills**: Enhanced abilities in technical observation, rapid note-taking, and synthesizing expert knowledge.

### Applying to Work

- **Workshop Project Execution**: Applied sound architecture principles, focusing on multi-layer web security configuration and SLA health monitoring.
- **Personal Development Planning**: Established a structured study roadmap for taking the AWS Cloud Practitioner exam.
- **Report Quality Enhancement**: Applied technical diagramming and synthesis skills to weekly FCAJ internship reports.

### Event Experience

The Cloud Architect Final & Technical Sharing event offered an enriching learning experience. The synergy between the final competition and expert talks reinforced my cloud architecture design mindset, elevated web security awareness, and laid a clear path toward AWS certifications.
