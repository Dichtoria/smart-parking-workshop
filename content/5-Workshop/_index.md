# Deploying a Smart Parking System Integrated with AI & AWS Cloud

#### Workshop Overview

This workshop provides a step-by-step practical guide to building and deploying a complete **Smart Parking System** on AWS. The solution embeds Computer Vision AI (ANPR license plate recognition & QR code parking reservations), VNPay online payment integration, and operates on a Serverless Container infrastructure.

#### Learning Objectives

- Master secure identity management and permissions with **AWS IAM & AWS CLI v2**.
- Deploy and manage **Amazon RDS PostgreSQL** relational databases with multi-layer Security Groups.
- Containerize Node.js backend applications using **Docker** and manage images on **Amazon ECR**.
- Orchestrate auto-scaling Serverless Containers with **Amazon ECS Fargate**.
- Accelerate API endpoints and provision automated HTTPS certificates with **Amazon CloudFront CDN**.
- Implement automated CI/CD deployment pipelines for React Vite Frontend using **AWS Amplify Hosting**.
